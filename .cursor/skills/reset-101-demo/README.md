# reset-101-demo

After a Cursor 101 demo, invoke **`/reset-101-demo`** in Agent chat (or run `bash .cursor/skills/reset-101-demo/reset.sh` from the repo root).

This restores `demo-base` to the `demo-reset` tag, reverts merged demo PRs on `master`, closes leftover factory/demo PRs, and moves Linear tickets back to Backlog.
